# Carpineto Romano, borgo digitale

Due applicazioni convivono in questo repository.

- [Lumina](lumina/README.md) — agenda per appuntamenti e corsi (PHP 8.5.12, MySQL o MariaDB di XAMPP). Parrucchieri, palestre e studi.
- [SpeakDay](english-speak/README.md) — allenamento quotidiano di inglese parlato.

# SpeakDay — English audio conversation routine

Interactive daily trainer for speaking English in **meetings** and **daily life**.

## Quick start

```bash
cd english-speak
npm install
npm run dev
```

See [`english-speak/README.md`](english-speak/README.md) for details.

Modelli menu MenuCraft
======================

menu-settimanale.csv
  Una settimana tipo (lunedì–venerdì). Colonne: data;codice;nome;categoria;prezzo
  Categorie ammesse: primo, secondo, contorno, frutta, yogurt, dessert, bevanda

menu-mensile.csv
  Un mese di giorni lavorativi con lo stesso formato.

Come usarli
  1. Apri il file e cambia le date se serve.
  2. Nel backend, sezione Menu, carica il CSV con «Carica menu».
  3. Il sistema pubblica i piatti sui giorni indicati; le lettere ripartono da A B C.

Puoi anche usare un Excel del giovedì a griglia, oppure salvare questi CSV come .xlsx.

Import utenti
=============
utenti-import.csv
  Colonne: matricola;nome;password;pagamento;allergie;saldo
  pagamento: eredita | busta | buono | pagante | welfare
  Nel backend, sezione Utenti: «Scarica template» poi «Importa utenti».
  Matricole già presenti vengono aggiornate (password vuota = lascia invariata).

Password dipendente
===================
Frontend: tab Password (non sullo scontrino). Login: «Password dimenticata?»
→ richiesta al catering; in Utenti si genera una password temporanea.

Export Excel + Reminder VB.NET
==============================
Form1 completo (da usare): Form1.vb
Module (anche standalone): ExportCucinaDataTable.vb
Esempio INI: config.mensa.example.ini
SQL: export-vbnet.sql

ini_method=2 → connectionDBM2() + ini_company (id, es. 5).

Export sera (oraInvio_ini): primo giorno utile DOPO oggi → Excel + mail.

Reminder (hour_ini_reminder / hour_ini_reminder2):
  utenti.email (la digiti tu) + mail_reminder=Y
  mattina  → chi non ha prenotato OGGI
  pomeriggio → chi non ha prenotato il primo giorno utile (ferie/chiusure/sab-dom)
  Orari cutoff presi da aziende.limite_oggi / limite_domani (default 09:30 / 18:00).

Nel backend Utenti: campi Email + Invia reminder; anche nel CSV import.

Import utenti con azienda
=========================
Template/export: api/template-utenti.php (colonna azienda = slug).
Catering: Scarica utenti/template già filtrato sulla propria società.
Piattaforma: template vuoto oppure “Scarica utenti” per cucina; import
accetta più aziende nello stesso file (una riga = una persona + slug).
Password vuota in aggiornamento non cambia quella già salvata.

Sovrascrivere la cartella sul server di lavoro
=============================================
Sì, puoi copiare tutta la cartella menucraft-ai/ sopra quella già installata.

Cosa succede al database
  Alla prima richiesta PHP (o aprendo index) gira Installer: crea tabelle mancanti
  e aggiunge colonne nuove. I dati già presenti (aziende, utenti, ordini, menu)
  restano. Non serve uno script SQL a mano.

Cosa NON sovrascrivere / controllare
  - config: se sul server hai password DB diverse, ripristina config/database.php
    o le variabili MENUCRAFT_DB_* dopo la copia.
  - assets/loghi/: i logo caricati stanno qui; se li cancelli spariscono dalle pagine.
  - Non cancellare il database MySQL “menucraft”: la cartella PHP non contiene i dati.

Se qualcosa non torna
  Ricarica una pagina (frontend o backend): le migrazioni ripartono da sole.
  Controlla che Apache/PHP punti alla cartella nuova e che MySQL sia acceso.
